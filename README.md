# RetailOps

Backend para la gestión de ventas e inventario multisucursal en un escenario retail.

> Proyecto desarrollado como simulación de un caso empresarial real del sector retail con fines de aprendizaje y portafolio profesional.

## Problema de negocio

Una cadena ficticia de minimarkets presenta inconsistencias entre sus ventas y el inventario de sus diferentes sucursales.

Entre los principales problemas se encuentran:

- ventas de productos sin stock disponible;
- diferencias entre ventas registradas e inventario;
- falta de trazabilidad de movimientos de stock;
- inventarios independientes por sucursal;
- ausencia de control adecuado de permisos;
- posibles operaciones incompletas ante errores durante una venta.

## Objetivo

Desarrollar una API backend que permita gestionar productos, sucursales, inventario y ventas manteniendo la consistencia de los datos y la trazabilidad de las operaciones.
